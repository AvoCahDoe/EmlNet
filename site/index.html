Deploy

This folder is static: upload site/ to any static host (GitHub Pages, Netlify, S3, nginx, etc.).

Local preview:
cd site && python -m http.server 8080 then open http://localhost:8080

Sweep: run python -m emlnet_pkg.train_sweep from EMLnet/, then python -m emlnet_pkg.build_sweep_site to copy plots/sweep/ into site/sweep/ and install data/sweep_manifest.json. The site prefers that manifest when present.
